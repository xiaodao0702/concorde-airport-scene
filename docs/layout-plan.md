## 二、对称性与动线

- **规整对称**：主跑道居中（z=0），滑行道/停机坪在北侧呈南北对称的机场功能分区；
  边界围墙/铁丝网为矩形闭环（x∈[-35.5,35.5], z∈[-18.5,34.5]），四角界碑对称。
- **动线合理**：协和号沿主跑道自西向东起飞（姿态：机头微抬 3.7°，主轮离地约 6cm）→
  快速脱离道 → 平行滑行道 → 停机坪（3 个停机位）→ 库房/塔台/油罐区各司其职；
  南大门进车、北便门进人，油罐区围堰+防火分隔，符合军用机场规范布局。
